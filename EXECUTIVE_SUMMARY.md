# OffHours — Executive Summary

**What it is:** A marketplace concept for renting restaurant kitchens during off-hours — after the restaurant closes.

**How it works (demo):** Listings and booking flow run entirely in the browser. Live demo at https://nelsen3000.github.io/offhours/

**Status:** Demo only. Bookings and licenses stay in the browser — no backend, no real payments.

**Stack:** Single-page static site (`index.html`, `app.js`, `data.js`, `styles.css`), hosted on GitHub Pages.
